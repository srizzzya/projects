# 🌥️ Cloud Pages: A Quote Generator

Welcome to **Cloud Pages**, a tiny web experience where whispers of poetry float through the screen. Built using HTML, CSS, and JavaScript (baby’s first JS moment 🐣), this quote generator was born out of pure vibes and a desire to romanticize the web.

## ✨ Features
- A soft, aesthetic landing page
- Scrolls into a quote generator with handpicked poetic lines
- Random quote generation with each click
- Fully responsive & styled with external CSS
- Smooth transitions and a touch of dreamcore energy 🌙

## 💻 Tech Stack
- HTML
- CSS
- JavaScript
